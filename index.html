Data notes

· log rows processed = JSON lines read from the Zeek logs (conn, dns, ssl, arp, icmp_live, other_ip).
· log rows/s = rate of new rows arriving, sampled once per second.
· history samples = 1-second up/down snapshots feeding the traffic chart (max 90).
· UI: flows cut = flows trimmed from the UI snapshot when the table exceeds 1500.
· DNS counting: each Zeek dns.log row is one transaction — it always starts as a query; if the row carries an RCODE/RTT, the reply was seen. "Evicted" = oldest events rotated out of the bridge ring (500) or UI buffer (1200) — buffer eviction, not packet loss.
· DNS domains and TLS SNI come only from observed plaintext metadata; DoH/DoT, ECH, QUIC and VPNs can hide them. An IP→domain match is an association, not proof. URLs/paths/search terms are never recoverable from encrypted traffic.
